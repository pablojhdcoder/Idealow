# Pack de documentación para pruebas (misma idea)

Este paquete contiene documentación de ejemplo sobre una misma idea para adjuntar en el formulario.

Idea central: **IdeaLow FlashLearn**, plataforma que transforma ideas de negocio en microcursos accionables con validación de mercado y acompañamiento por IA.

Archivos incluidos:
- `01_resumen_ejecutivo.txt` (`text/plain`)
- `02_pitch_detallado.md` (`text/markdown`)
- `03_dossier_tecnico.pdf` (`application/pdf`)
- `04_texto_para_capture_new_idea.txt` (texto listo para pegar en `Capture a new idea`)

Sugerencia de prueba:
1. Adjuntar el `.txt`, `.md` y `.pdf` en el flujo de nueva idea.
2. Pegar el contenido del archivo `04_texto_para_capture_new_idea.txt` en el recuadro de texto.
3. Verificar que la extracción de contexto y refinamiento mantengan consistencia entre todos los adjuntos.
